# 데일리루트 (Daily Route)

> 당신의 평범한 일상 경로를, AI가 매력적인 로컬 여행 콘텐츠로 재구성해주는 서비스.

**Live demo**: https://trip-guid.vercel.app

## 프로젝트 개요

여행 콘텐츠는 대부분 유명 관광지 중심으로 소비됩니다. 하지만 개인의 일상 경로(출퇴근길, 동네 산책로 등)는 그 지역을 모르는 사람에게는 새로운 로컬 경험이 될 잠재력이 있습니다. 데일리루트는 이 경로를 한 문장으로 입력받아 주변 장소를 큐레이션하고 스토리텔링해서, SNS에 공유할 수 있는 매력적인 "로컬 가이드 콘텐츠"로 재구성해주는 서비스입니다.

- **왜 만들었나**: 풀스택 개발 역량(프론트/백엔드/AI 연동/배포)과 프리미엄 모델을 포함한 제품 기획력을 증명하기 위한 포트폴리오 프로젝트입니다.
- **차별점**: 유명 관광지가 아니라 "누군가의 일상"을 여행 콘텐츠로 재해석한다는 프레이밍
- **기술 스택**: Next.js (App Router, TypeScript) · Tailwind CSS v4 · Vitest · Vercel 배포

## 어떻게 작동하나요

1. **경로 입력** — 랜딩 화면(`/`)에서 일상 경로를 한 문장(10~300자)으로 적어 제출합니다.
2. **생성** — `/generate`로 이동해 로딩 화면(3단계 스테퍼)이 보이는 동안 `POST /api/routes/generate`가 코스를 만듭니다. 등급(무료/프리미엄)에 따라 스팟 3개 또는 5개가 포함된 코스 JSON을 반환합니다.
3. **결과 확인** — 코스 제목·소개와 스팟별 카드(이름/카테고리/설명)가 렌더링됩니다.
4. **저장 또는 공유** — "저장하기"로 공개/비공개를 선택해 브라우저에 저장하거나, "공유하기"로 코스를 PNG 이미지 카드로 내보낼 수 있습니다.
5. **다시 찾아보기** — `/my`(내 코스)에서 저장한 코스를 필터링하고, `/gallery`에서 이 브라우저가 공개로 저장한 코스를 최신순으로 둘러봅니다.
6. **등급 전환** — `/plan`에서 무료/프리미엄 기능 차이를 비교하고, 가짜 구매 플로우를 거쳐 등급을 전환해볼 수 있습니다.
7. **체크인 & AI 여행기** (프리미엄) — `/my/[id]`에서 코스의 각 스팟에 체크인 기록을 남기고, 모든 스팟을 완료하면 그 기록을 바탕으로 개인화된 여행기를 생성합니다.

이 모든 과정에서 **회원가입/로그인은 없습니다.** 브라우저가 처음 방문 시 스스로 발급한 `anonymousId`(로컬 저장소에 보관되는 UUID)로 사용자를 식별하며, 저장된 코스·등급 상태는 전부 이 값에 연결됩니다.

## 주요 기능

| 화면 | 기능 |
|---|---|
| **랜딩 · 경로 입력** (`/`) | 일상 경로를 한 문장으로 입력. 10자 미만/300자 초과 시 제출 차단 및 에러 메시지 표시 |
| **생성 중 로딩** (`/generate`) | "경로에서 장소 읽기 → 주변 장소 찾기 → 코스 만들기" 3단계 스테퍼로 진행 상태 표시. 백엔드 응답까지 자동 대기 후 결과 화면으로 전환 |
| **결과 화면** | 코스 제목/소개, 스팟 카드 목록(번호·이름·카테고리·설명). 헤더에 현재 등급과 스팟 개수 표시 |
| **저장 · 공개 설정** | 저장 시 공개(갤러리 노출)/비공개(나만 보기) 중 선택. 로그인 없이 브라우저에만 저장된다는 안내 포함 |
| **공유 카드** | 코스를 카드 이미지 미리보기로 보여주고 PNG로 다운로드. 무료 등급은 워터마크 포함, 프리미엄은 워터마크 제외 |
| **내 코스** (`/my`) | 저장한 코스를 전체/공개/비공개로 필터링해서 그리드로 확인. 코스 클릭 시 상세 화면(`/my/[id]`)으로 이동. 빈 상태에서는 첫 코스 만들기 CTA 표시 |
| **갤러리** (`/gallery`) | 이 브라우저가 공개로 저장한 코스만 최신순으로 노출(다른 사용자와의 실제 공유는 아님). 가장 최근 코스는 Editor's pick 형태로 강조 |
| **등급 비교 · 결제** (`/plan`) | 무료/프리미엄 기능 차이(스팟 개수, 워터마크, 체크인·여행기 여부)를 표로 비교. "프리미엄 구매하기" → 가짜 결제 화면 → 완료 처리 순으로 등급 전환. 데모 편의를 위한 "무료로 되돌리기" 버튼 포함 |
| **체크인 + AI 여행기** (`/my/[id]`, 프리미엄 전용) | 저장한 코스의 스팟마다 한 줄 기록(+사진 미리보기)을 남기고, 모든 스팟을 완료하면 그 기록을 엮은 여행기를 생성. 무료 등급에는 잠금 UI와 프리미엄 안내만 표시 |

각 화면의 완료 조건·엣지 케이스는 [`docs/slices/`](./docs/slices)에 기능별로 정리돼 있습니다.

## 서비스에 필요한 추가 설명

- **데이터는 전부 이 브라우저에만 저장됩니다.** 회원가입/로그인이 없는 대신, 저장한 코스와 등급 상태는 브라우저 로컬 저장소(`localStorage`)에만 존재합니다. 브라우저 데이터를 지우거나 다른 기기·브라우저로 접속하면 이전 데이터에는 접근할 수 없습니다.
- **현재는 Phase 0(프로토타입, 목업 데이터) 단계입니다.** `POST /api/routes/generate`는 실제 카카오 지오코딩·LLM 연동 없이 등급별로 고정된 목업 코스(무료 3스팟/프리미엄 5스팟)를 반환합니다. 실제 API 연동은 이후 Phase 1에서 진행될 예정입니다. 로드맵은 [`docs/prd.md`](./docs/prd.md) 8장을 참고하세요.
- **프리미엄 결제는 실제로 이루어지지 않습니다.** "프리미엄 구매하기"는 등급 전환 UX를 시연하기 위한 가짜 결제 플로우이며, PG사 연동이 없습니다. 데모 편의를 위해 `/plan`에서 언제든 "무료로 되돌리기"로 등급을 초기화할 수 있는데, 이는 실제 서비스라면 없을 기능입니다.
- **갤러리는 "가짜" 버전입니다.** 실제로 여러 사용자 간 코스를 공유하는 백엔드는 없고, 지금 보고 있는 브라우저가 직접 공개로 저장한 코스만 모아서 보여줍니다.
- **체크인 사진은 저장되지 않습니다.** 사진은 그 세션 동안만 미리보기로 보이고, 새로고침하면 사라집니다. 텍스트 기록과 생성된 여행기만 영구적으로 저장됩니다.
- **공유 카드 이미지 저장이 드물게 실패할 수 있습니다.** `html-to-image` 기반 PNG 변환이 간헐적으로 멈추는 알려진 이슈가 있어, 8초 타임아웃 후 에러 메시지를 보여주고 재시도할 수 있게 처리해뒀습니다.

## 시작하기

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000)에서 확인할 수 있습니다.

```bash
npm test        # vitest run — 계산/판단 로직(src/lib/*) 위주 단위 테스트
npm run lint
npm run build
```

## 프로젝트 구조

```
src/
├─ app/
│  ├─ page.tsx                  # 랜딩 · 경로 입력 (/)
│  ├─ layout.tsx                # 루트 레이아웃, 폰트/메타데이터
│  ├─ validateRouteInput.ts     # 입력 길이 검증 순수 함수
│  ├─ generate/
│  │  ├─ page.tsx               # /generate — searchParams에서 입력 텍스트 전달
│  │  ├─ GenerateClient.tsx     # 로딩 → 결과 화면 클라이언트 컴포넌트
│  │  ├─ loadingPhase.ts        # 로딩 스테퍼 단계 계산
│  │  ├─ SaveModal.tsx          # 저장 · 공개 설정 모달
│  │  └─ ShareModal.tsx         # 공유 카드 미리보기 · PNG 내보내기
│  ├─ my/
│  │  ├─ page.tsx               # /my — 내 코스 목록/필터
│  │  └─ [id]/page.tsx          # /my/[id] — 코스 상세, 체크인 · AI 여행기
│  ├─ gallery/page.tsx          # /gallery — 공개 코스 갤러리
│  ├─ plan/page.tsx             # /plan — 등급 비교 · 가짜 결제 플로우
│  └─ api/routes/generate/route.ts  # 목업 코스 생성 API
└─ lib/                         # storage 주입 패턴의 순수 함수 모음 (테스트 대상)
   ├─ anonymousId.ts            # anonymousId 발급/조회
   ├─ savedRoutes.ts            # 코스 저장/조회/필터/정렬
   ├─ tier.ts                   # 무료/프리미엄 등급 상태
   ├─ checkins.ts               # 체크인 기록, 완주 판정, 여행기 생성
   └─ shareFileName.ts          # 공유 이미지 파일명 생성

docs/
├─ concept.md                   # 핵심 컨셉
├─ feature-spec.md              # 화면별 기능 상세
├─ prd.md                       # 요구사항(FR/NFR), 범위, 성공지표
├─ business-model.md            # 수익 모델(포트폴리오용 사고 실험)
└─ slices/                      # 기능별 구현 스펙 (완료 조건 · 확인 방법 등)
```

기획/설계 문서는 항상 `docs/*.md`가 원본(source of truth)이며, 프로젝트 전체 규칙은 [`CLAUDE.md`](./CLAUDE.md), 세션별 실행 계획은 [`PLAN.md`](./PLAN.md)를 참고하세요.
