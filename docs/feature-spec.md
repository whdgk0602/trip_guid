# 기능 명세서: 동네 큐레이터

> 대상 독자: 개발자(본인) · 관련 문서: [concept.md](./concept.md) · [prd.md](./prd.md)
> 이 문서는 기능 구체화 결과를 화면/시나리오 단위로 상세히 정리한 문서. PRD의 요구사항이 실제로 어떻게 동작하는지 명세한다.

## 1. 핵심 사용자 시나리오

| 시나리오 | 설명 |
|---|---|
| A. 코스 생성 | 제작자가 경로를 입력해 AI 코스를 생성받는다 |
| B. 저장 및 공개 설정 | 생성된 코스를 저장하고 공개 여부를 정한다 |
| C. 공유 카드 생성 | 코스를 SNS 공유용 이미지로 내보낸다 |
| D. 갤러리 탐색 | 소비자가 공개된 코스를 둘러본다 |
| E. 체크인 + AI 여행기 (스트레치) | 코스를 실제로 걸으며 기록을 남기고 여행기를 받는다 |

## 2. 화면별 기능 상세

### 2.1 랜딩/입력 화면
- 서비스 소개 히어로 영역 + 텍스트 입력 필드 1개 (경로 서술)
- 입력 가이드 placeholder 제공 (예: "출근길에 대림역에서 2호선 갈아타고 강남역에서 내려요") — AI 큐레이션 품질이 입력 구체성에 좌우되므로 예시로 유도
- 글자 수 제한: 10~300자
- 제출 시 로딩 화면으로 전환

### 2.2 생성 중 로딩 화면
- 단계별 상태 텍스트 전환 ("주변 장소 찾는 중" → "코스 만드는 중")
- 실패 시 에러 메시지 + 재시도 버튼

### 2.3 결과 화면
- 코스 제목 / 스토리텔링 소개
- 스팟 카드 리스트 (무료 등급: 3개, 프리미엄: 5개 — 4장 참고)
- 액션: 저장하기(공개/비공개 선택 모달) · 공유하기(카드 미리보기/다운로드) · 다시 만들기(같은 입력으로 재생성)

### 2.4 마이페이지
- 내가 만든 코스 그리드 (공개/비공개 배지 표시)
- 저장 후에도 공개/비공개 토글 가능
- 빈 상태 UI: "아직 만든 코스가 없어요" + 입력 화면 유도 CTA

### 2.5 갤러리
- 공개로 설정된 코스만 그리드로 노출, 기본 정렬은 최신순
- 카테고리 필터 등은 후순위(스트레치 이후)

### 2.6 무료/프리미엄 안내
- 무료 vs 프리미엄 비교 화면 (4장 표 기준)
- "프리미엄 구매하기" 버튼 → 가짜 결제 화면(가격/결제수단 UI 표시) → 완료 화면 → 등급 전환
- 실제 PG사 연동은 없음 (범위 밖, business-model.md 참고). 데모 설득력을 위해 실제 구매 플로우처럼 보이는 UI로 구현

### 2.7 체크인 + AI 여행기 (스트레치, 프리미엄 전용)
- 체크인: 스팟별 한 줄 기록 + 사진 1장
- 코스 완주 후 "여행기 생성" 버튼 → AI가 기록을 종합해 개인화된 여행기 생성

## 3. 사용자 식별 방식 (비로그인)

- 최초 방문 시 브라우저에 `anonymousId`(UUID)를 생성해 로컬 저장소에 보관
- 저장한 코스, 등급(무료/프리미엄) 상태는 이 `anonymousId`에 매핑
- **제약**: 브라우저 데이터 삭제·기기 변경 시 `anonymousId`가 유실되어 기존 코스에 접근 불가 — 저장/등급 관련 화면에 안내 문구 필요

## 4. 등급별 기능 게이팅

사용량 제한(월 N회 생성 등) 대신 **기능 단위로 등급을 구분**한다. 비로그인 구조에서는 사용량 카운트가 로컬 저장소 삭제로 쉽게 우회되어 실효성이 낮기 때문.

| 구분 | 무료 | 프리미엄 |
|---|---|---|
| 코스 생성 | 가능 | 가능 |
| 스팟 개수 | 3개 | 5개 |
| 공유 카드 | 워터마크 포함 | 워터마크 없음 |
| 체크인 + AI 여행기 | 잠금 | 이용 가능 |

등급 상태는 Phase 0에서는 로컬 목업(anonymousId에 플래그), Phase 1에서 결제 연동 시 서버 매핑으로 전환.

## 5. 에러 및 엣지 케이스

| 상황 | 처리 |
|---|---|
| 입력 텍스트가 너무 짧거나 장소를 특정할 수 없음 | 재입력 유도 메시지 |
| LLM이 텍스트에서 지명을 추출하지 못함 (구어체, 오타, 지명 없음 등) | "장소를 인식하지 못했어요, 다시 입력해주세요" 안내 + 예시 문구 재노출 |
| 추출된 지명을 카카오 지오코딩 API가 좌표로 변환하지 못함 | 동일하게 재입력 안내 (지명 철자/표기 문제일 가능성 언급) |
| 주변 장소가 3개 미만 (카카오 API 기준) | 반경을 확대해 재검색, 그래도 부족하면 사용자에게 안내 후 가능한 개수로 진행 |
| AI 생성 콘텐츠에 부적절한 표현 포함 가능성 | Phase 1에서 콘텐츠 필터링 적용 (오픈 이슈) |
| anonymousId 유실 | 저장된 코스 접근 불가 안내, 새 anonymousId로 재시작 |

## 6. 범위 밖 (이번 라운드에서 제외)

- 지도 기반 경로 입력 (텍스트 입력만 지원)
- 실제 결제 연동 (등급 토글 UI만 제공)
- 사용량 기반 과금
