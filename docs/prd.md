## 1. 배경 및 문제 정의

여행 콘텐츠는 대부분 유명 관광지 중심으로 소비된다. 반면 개인의 일상 경로(출퇴근길, 동네 산책로 등)는 그 지역을 모르는 사람에게 새로운 로컬 경험이 될 잠재력이 있지만, 이를 콘텐츠화해주는 서비스는 없다.

**해결하려는 문제**: 개인의 일상 경로를 매력적인 로컬 여행 콘텐츠로 변환해주는 도구의 부재.

## 2. 목표

| 구분 | 목표 |
|---|---|
| 제품 목표 | 경로 입력 → AI 큐레이션 → 공유 가능한 로컬 코스 콘텐츠 생성까지의 핵심 루프를 매끄럽게 제공 |
| 개인 목표 (포트폴리오) | 풀스택 개발 역량(프론트/백엔드/AI 연동/배포) 및 프리미엄 모델을 포함한 제품 기획력을 증명하는 완성도 있는 결과물 확보 |

## 3. 성공 지표

| 지표 | 목표치 | 비고 |
|---|---|---|
| 핵심 플로우 완주 | 입력→결과→저장/공유까지 이탈 없이 진행 가능 | 자체 검증 중심 (초기 단계) |
| 배포 가능 여부 | 실제 접속 가능한 URL 존재 | 포트폴리오 필수 조건 |
| 예시 콘텐츠 수 | 직접 제작한 공개 코스 5개 이상 갤러리 노출 | 빈 서비스로 보이지 않게 |
| 공유 카드 완성도 | SNS 공유 시 시각적으로 매력적인지 (주관 평가) | 바이럴 포인트, 우선순위 높음 |
| 프리미엄 게이팅 동작 | 무료/프리미엄 등급별 기능 차이가 UI에 명확히 반영 | 사업 모델 구현 증빙 |

## 4. 타겟 사용자

- **제작자(Primary)**: 자신의 동네/일상 루트를 콘텐츠로 만들어보고 싶은 20~30대, 모바일 우선 사용
- **소비자(Secondary)**: 갤러리를 통해 남이 만든 로컬 코스를 둘러보는 사용자

## 5. 범위

### 5.1 In Scope (MVP)
- 경로 텍스트 입력
- AI 기반 장소 큐레이션 및 콘텐츠(제목/소개/스팟 설명) 생성
- 공유 카드 이미지 생성 (등급별 워터마크 차등)
- 코스 저장(비로그인, 디바이스 기반) + 공개/비공개 선택, 마이페이지·갤러리
- 무료/프리미엄 등급 게이팅 (기능 단위, 상세는 feature-spec.md 4장)

### 5.2 Stretch (여유 시)
- 코스 완주 체크인 기록 (한 줄 기록 + 사진) — 프리미엄 전용
- AI 기반 개인 여행기 자동 생성 — 프리미엄 전용

### 5.3 Out of Scope
- 실시간 GPS 트래킹
- 지도 기반 경로 입력 (텍스트 입력만)
- 팔로우/댓글 등 소셜 그래프 기능
- 실제 결제 연동 (등급 전환은 가짜 구매 플로우 UI로만 시연, PG사 연동 없음)
- 사용량 기반 과금
- 회원가입/로그인
- 다국어 지원

## 6. 요구사항 (Functional Requirements)

우선순위: **P0**(MVP 필수) · **P1**(MVP 권장) · **P2**(스트레치)

| ID | 요구사항 | 우선순위 | 수용 기준 |
|---|---|---|---|
| FR-1 | 사용자는 텍스트로 경로를 서술하여 입력할 수 있다 | P0 | 10~300자 입력 후 제출 시 생성 프로세스로 진입 |
| FR-2 | 시스템은 입력 텍스트에서 지명/장소를 추출(LLM)하여 카카오 지오코딩 API로 좌표로 변환한다 | P0 | 인식된 지명 기준으로 좌표 확보. 지명을 추출하지 못하거나 지오코딩 실패 시 재입력 안내(feature-spec.md 5장 에러 케이스 참고) |
| FR-3 | 시스템은 변환된 좌표 주변 장소를 수집하고 평점/카테고리 다양성 기준으로 큐레이션한다 | P0 | 등급별 개수(무료 3개/프리미엄 5개)만큼 스팟 포함, 부족 시 반경 확대 후 대체 |
| FR-4 | 시스템은 코스 제목/소개, 스팟별 설명을 자동 생성한다 | P0 | 생성된 텍스트가 스토리텔링 톤을 유지 |
| FR-5 | 사용자는 생성된 코스를 저장할 수 있다 | P0 | 저장 시 공개/비공개 선택, 이후 마이페이지에서 토글 가능 |
| FR-6 | 사용자는 생성된 코스를 SNS 공유용 이미지 카드로 내보낼 수 있다 | P0 | 무료 등급은 워터마크 포함, 프리미엄은 미포함. 다운로드 가능 |
| FR-7 | 사용자는 마이페이지에서 본인이 만든 코스 목록(공개+비공개)을 볼 수 있다 | P0 | 그리드 표시, 공개 상태 배지, 빈 상태 UI |
| FR-8 | 사용자는 갤러리에서 공개로 설정된 코스를 둘러볼 수 있다 | P0 | 비공개 코스는 노출되지 않음 |
| FR-9 | 시스템은 브라우저 로컬 저장소 기반 anonymousId로 사용자를 식별한다 | P0 | 로그인 없이 저장/등급 상태가 anonymousId에 연결됨 |
| FR-10 | 사용자는 무료/프리미엄 등급 안내 화면에서 가짜 구매 플로우를 거쳐 등급을 전환해볼 수 있다 | P0 | "프리미엄 구매하기" → 가짜 결제 화면 → 완료 처리 순으로 진행, 실제 결제 연동 없이 등급별 기능 차이를 확인 가능 |
| FR-11 | (프리미엄) 사용자는 코스를 걸으며 스팟별 체크인 기록(텍스트+사진)을 남길 수 있다 | P2 | 무료 등급에서는 잠금 UI로 표시 |
| FR-12 | (프리미엄) 시스템은 체크인 기록을 기반으로 개인화된 여행기를 자동 생성한다 | P2 | 감정/키워드가 반영된 문단 형태 결과 제공 |

## 8. 마일스톤

Phase 0(프로토타입, 목업 데이터) → Phase 1(백엔드 연동) → Phase 2(스트레치, 프리미엄 게이팅 포함) 순서. 세부 태스크는 별도 개발 명세서 작성 시 정의.

**배포**: Vercel을 통해 배포. Phase 0(목업 데이터) 단계부터 배포해 프로토타입을 URL로 공유 가능한 상태 유지.
