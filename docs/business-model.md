# 비즈니스 모델: 동네 큐레이터

> 목적: 이 문서는 실제 수익화 실행 계획이 아니라, **포트폴리오/면접에서 제품 사고력을 보여주기 위한 전략 문서**다. 추정 수치는 시장조사가 아닌 논리적 가정임을 명시한다. 관련 문서: [prd.md](./prd.md) · [feature-spec.md](./feature-spec.md)

## 1. 가치 제안

| 구분 | 내용 |
|---|---|
| 고객이 하려는 일 (Job) | 자신의 일상을 콘텐츠로 만들고, 로컬 경험을 SNS에 공유하고 싶다 |
| 불편함 (Pain) | 매력적인 여행 콘텐츠를 직접 기획·작성하려면 시간과 감각이 필요함 |
| 얻는 가치 (Gain) | 텍스트 한 줄만 입력하면 AI가 큐레이션·스토리텔링을 대신해 즉시 공유 가능한 결과물을 만들어줌 |

## 2. 타겟 세그먼트

- **Primary**: SNS 활동이 활발한 20~30대, 자신의 일상을 콘텐츠화하는 데 관심 있는 로컬 크리에이터 지향층
- **Secondary**: 갤러리를 통해 로컬 콘텐츠를 소비하는 사용자 (전환 후보군)

## 3. 수익 모델: B2C 프리미엄 (Freemium)

무료 사용자를 넓게 확보하고, 콘텐츠 품질·소유 경험을 강화하고 싶은 사용자를 유료로 전환하는 구조.

| 구분 | 무료 | 프리미엄 |
|---|---|---|
| 스팟 개수 | 3개 | 5개 |
| 공유 카드 | 워터마크 포함 | 워터마크 없음 |
| 체크인 + AI 여행기 | 미지원 | 지원 |
| 가격(가정) | - | 월 4,900원 또는 연 결제 할인 |

가격은 유사 AI 콘텐츠 생성 서비스의 일반적인 구독료 대역을 참고한 가정치이며, 실제 책정 전 시장 검증이 필요하다는 점을 오픈 이슈로 남긴다.

## 4. 성장 전략

1. **획득**: 무료 사용자의 워터마크 포함 공유 카드가 SNS에 퍼지면서 자연 유입 채널 역할 (바이럴 루프)
2. **전환**: 워터마크 제거·더 풍부한 스팟·체크인 기반 여행기 기능으로 프리미엄 전환 유도
3. **확장(장기, 현재 범위 밖)**: 트래픽이 확보되면 아래 옵션 중 하나로 사업 확장 가능
   - 로컬 비즈니스(카페·식당) 대상 스폰서 노출 — B2B 광고
   - 지자체/관광공사 대상 "로컬 콘텐츠 자동 생성 툴" B2B/B2G SaaS

## 5. 경쟁 구도

| 카테고리 | 예시 | 차별점 |
|---|---|---|
| 여행 플래너 앱 | 마이리얼트립, 트리플 | 목적지·예약 중심, "내 일상을 콘텐츠화"하는 관점 없음 |
| SNS 콘텐츠 제작 도구 | 캡컷, 미리캔버스 | 장소/여행 맥락과 무관한 범용 편집 도구 |

**결론**: "유명 관광지가 아닌 개인의 일상을 로컬 여행 콘텐츠로 재해석"하는 포지셔닝은 현재 시장에서 비어 있는 틈새다.

## 6. 리스크

| 리스크 | 내용 |
|---|---|
| 전환 유인 부족 | 스팟 개수·워터마크 차이만으로는 유료 전환 동기가 약할 수 있음 — 체크인/AI 여행기 스트레치 기능의 매력도가 실질적인 전환 축이 될 가능성이 큼 |
| 게이팅 우회 | 비로그인·anonymousId 구조라 로컬스토리지 삭제로 무료 등급 재획득이 가능 — 포트폴리오 단계에서는 허용, 실서비스 전환 시 계정 시스템 필요 |
| 콘텐츠 품질 의존도 | 수익 모델 전체가 AI 생성 콘텐츠의 매력도에 의존 — 품질이 곧 전환율 |

## 7. 향후 확장 옵션 (현재 범위 밖)

- B2B 로컬 비즈니스 제휴 (스폰서 스팟 노출)
- B2G 로컬 관광 콘텐츠 SaaS
- 사용량 기반 과금으로 전환 (계정 시스템 도입 후)
