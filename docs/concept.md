# 앱 컨셉

> 이 프로젝트를 처음부터 다시 시작하며, 아래 컨셉만 남기고 나머지 기획/기술 문서와 프로젝트 세팅은 초기화함 (2026-08-23)

## 한 줄 소개

당신의 평범한 일상 경로를, AI가 매력적인 로컬 여행 콘텐츠로 재구성해주는 서비스. ("데일리루트")

## 핵심 아이디어

일상 루트(출퇴근길, 동네 산책로 등)를 입력하면 AI가 주변 장소를 큐레이션하고 스토리텔링해서, 그 지역을 모르는 사람에게는 매력적인 "로컬 가이드 콘텐츠"로 보이게 만들어준다. 결과물은 SNS 공유용 카드 형태로 출력된다.

**스트레치 아이디어**: 실제로 그 코스를 걸으며 감정/기록을 남기면, AI가 개인화된 여행기(회고)를 자동 생성해준다.

## 왜 이 프로젝트인가

- 목적: 풀스택 개발 포트폴리오 (취업/이직) + AI 연동 경험
- 경험 수준: 중급~숙련
- 투입 가능 시간: 약 1~2개월
- 차별점: 유명 관광지가 아닌 "누군가의 일상"을 여행 콘텐츠로 재해석한다는 프레이밍

## 이전 논의에서 나온 방향성 메모 (참고용, 확정 아님)

- 로그인 없이 디바이스 기반으로 시작하는 안이 검토된 적 있음
- 카카오맵 SDK 기반 지도 입력이 검토된 적 있음
- 이번 리셋으로 위 세부 사항은 모두 다시 논의 대상
