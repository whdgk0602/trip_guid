# 기능 5: 사용자가 마이페이지에서 공개/비공개로 코스를 필터링해서 볼 수 있다

> PRD FR-7 나머지 부분(필터, 빈 상태) · feature-spec.md 2.4. 코드 없음, 스펙만.

## 완료 조건

- [ ] `/my`에 저장된 코스가 있으면 상단에 필터 버튼 3개(전체/공개/비공개)가 보이고, 각 버튼에 해당 개수가 표시된다 (예: "전체 4", "공개 2", "비공개 2")
- [ ] "공개" 필터를 누르면 공개 코스만, "비공개"를 누르면 비공개 코스만 보인다. "전체"를 누르면 다시 다 보인다
- [ ] 저장된 코스가 하나도 없으면 필터 버튼 없이 "아직 만든 코스가 없어요" 문구와 입력 화면으로 이동하는 CTA 버튼이 보인다

## 안 되는 경우

- 특정 필터(예: "공개")를 보는 중에 배지를 눌러 코스를 "비공개"로 바꾸면, 그 코스는 더 이상 현재 필터 조건에 맞지 않으므로 목록에서 바로 사라진다 (필터를 다시 "전체"나 "비공개"로 바꿔야 보임)

## 이번에 안 하는 것

- MVP_DESIGN 비주얼 디자인(그리드 카드, 배지 색상 정식 스타일 등) — 다음 디자인 적용 라운드
- 코스 삭제 기능
- 정렬 옵션(최신순 등)
- 코스별 스팟 요약 문구, 저장 날짜 표시 (feature-spec 2.4에 언급되지만 이번 슬라이스 범위 밖)

## 건드릴 파일

- **고칠 파일**: `src/app/my/page.tsx` — 필터 상태(`all` / `public` / `private`)를 두고, 필터 버튼과 필터링된 목록을 렌더링. 코스가 없을 때는 필터 버튼 대신 빈 상태 CTA만 보이도록 분기
- **새로 만들 파일**: 없음. 필터링 로직은 `src/lib/savedRoutes.ts`에 순수 함수 `filterRoutesByVisibility(routes, filter)`를 추가해서 재사용 (새 파일 아님, 기존 파일에 함수 추가)
- **테스트**: `src/lib/savedRoutes.test.ts`에 `filterRoutesByVisibility` 테스트 추가

## 확인 방법

1. `npm run dev` 실행
2. `/`에서 코스를 2~3개 생성해 공개/비공개 섞어서 저장
3. `/my`에서 필터 버튼과 개수가 맞는지 확인
4. "공개"/"비공개"/"전체" 클릭 시 목록이 올바르게 필터링되는지 확인
5. 필터가 "공개"인 상태에서 배지를 눌러 비공개로 바꾸면 그 항목이 목록에서 사라지는지 확인
6. 저장된 코스를 모두 지운 상태(devtools localStorage 비우기)에서 `/my`에 접속해 빈 상태 CTA가 보이는지 확인
7. 자동화 테스트: `filterRoutesByVisibility` 순수 함수 테스트(vitest). 필터 버튼 클릭 등 UI 동작은 수동 확인 (01~04 슬라이스와 동일 방침)
