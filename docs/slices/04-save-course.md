# 기능 4: 사용자가 생성된 코스를 저장하고 공개/비공개를 정할 수 있다

> PRD FR-5 · FR-9 (anonymousId) · feature-spec.md 2.3/2.4/3장. 코드 없음, 스펙만.

## 완료 조건

- [ ] 결과 화면에서 "저장하기"를 누르면 공개/비공개 선택 모달이 뜬다
- [ ] 공개 또는 비공개를 선택해 저장하면, 같은 화면에 머문 채 모달이 "저장 완료" 상태(예: "저장했어요" + "내 코스 보기" 버튼)로 바뀐다
- [ ] "내 코스 보기"를 누르면 `/my`로 이동해 코스 제목과 공개/비공개 배지가 보인다
- [ ] 새로고침해도 저장한 코스가 남아있다
- [ ] `/my`에서 배지를 눌러 공개/비공개를 전환할 수 있고, 새로고침해도 바뀐 상태가 유지된다

## 안 되는 경우

- 선택 모달에서 "취소"를 누르면 저장되지 않고 결과 화면으로 돌아간다 (모달만 닫힘)

## 이번에 안 하는 것

- MVP_DESIGN 비주얼 디자인 적용 — 01~03 화면과 같은 방식으로, 이번엔 기능만 만들고 스타일은 최소로 둔 뒤 다음 라운드에서 디자인 적용
- 공유하기 · 다시 만들기 버튼 — 여전히 범위 밖 (feature-spec 2.3에 있지만 별도 슬라이스)
- 마이페이지 필터(전체/공개/비공개 탭), 그리드 카드 스타일 — FR-7의 나머지 부분은 다음 슬라이스. 이번엔 목록 + 배지 + 토글만
- 코스 삭제 기능
- 저장 개수 제한, 등급 게이팅(무료/프리미엄) — 4장 내용은 이후 슬라이스
- anonymousId 유실 시 안내 문구(NFR-6) — 이번엔 anonymousId를 만들고 저장에 쓰는 것까지만, 유실 시나리오 UI는 다음 슬라이스

## 건드릴 파일

- **새로 만들 파일**:
  - `src/lib/anonymousId.ts` — `getOrCreateAnonymousId(storage: Storage): string`. localStorage에서 기존 id를 읽고 없으면 `crypto.randomUUID()`로 생성해 저장 후 반환하는 순수 함수(storage를 인자로 받아 테스트 가능하게)
  - `src/lib/anonymousId.test.ts`
  - `src/lib/savedRoutes.ts` — 저장된 코스 배열에 대한 순수 함수: `addSavedRoute(routes, course, visibility) => SavedRoute[]`(id·저장시각 부여해 추가), `setSavedRouteVisibility(routes, id, visibility) => SavedRoute[]`(해당 id의 공개/비공개 전환). localStorage 읽기/쓰기는 이 파일의 얇은 wrapper 함수(`loadSavedRoutes`/`persistSavedRoutes`)에서만 담당
  - `src/lib/savedRoutes.test.ts`
  - `src/app/generate/SaveModal.tsx` — 공개/비공개 라디오 + 저장/취소 버튼을 가진 모달 컴포넌트
- **고칠 파일**:
  - `src/app/generate/GenerateClient.tsx` — 헤더의 "저장하기" 버튼에 모달 열기 연결, 저장 완료 후 상태 처리(물어볼 것 참고)
  - `src/app/my/page.tsx` — 기존의 죽은 `saved-routes` 문자열 배열 로직을 제거하고, `anonymousId` 기준으로 저장된 코스 목록(제목 + 공개/비공개 배지, 배지 클릭 시 토글)을 렌더링하도록 교체

## 확인 방법

1. `npm run dev` 실행
2. `/`에서 코스 생성 → 결과 화면에서 "저장하기" 클릭 → 공개/비공개 선택 모달이 뜨는지 확인
3. "공개"를 선택해 저장 → 같은 화면에서 모달이 "저장 완료" 상태(내 코스 보기 버튼 포함)로 바뀌는지 확인
4. "내 코스 보기" 클릭 → `/my`에서 제목과 "공개" 배지가 보이는지 확인
5. 새로고침 후에도 `/my`의 목록이 남아있는지 확인
6. `/my`에서 배지를 클릭해 "비공개"로 바뀌는지, 새로고침 후에도 유지되는지 확인
7. 다시 결과 화면으로 돌아가 선택 모달에서 "취소"를 눌렀을 때 저장되지 않는지 확인
8. 자동화 테스트: `anonymousId.test.ts`, `savedRoutes.test.ts`로 순수 로직(계산/판단) 검증. 모달 열림, `/my` 렌더링 등 UI 동작은 수동 확인(컴포넌트 테스트 라이브러리 미설치, 01~03 슬라이스와 동일한 방침)
