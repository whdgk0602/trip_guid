## 확인 방법

1. `npm run dev` 실행
2. `/`에서 코스를 2~3개 생성해 공개/비공개 섞어서 저장 (시간차를 두고 저장)
3. `/gallery` 접속 → 공개 코스만, 최신순으로 보이는지 확인
4. 비공개 코스는 보이지 않는지 확인
5. localStorage를 비우고 `/gallery` 접속 → 빈 상태 문구 확인
6. 랜딩 화면 헤더에서 "갤러리" 링크로 이동되는지 확인
7. 자동화 테스트: `sortRoutesByNewest` 순수 함수 테스트(vitest). 그리드 렌더링은 수동 확인
