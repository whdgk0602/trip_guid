# 기능 8: 사용자가 무료/프리미엄 등급 안내 화면에서 가짜 구매 플로우로 등급을 전환하고, 등급별 기능 차이를 확인할 수 있다

> PRD FR-3(스팟 개수), FR-6(워터마크), FR-10(가짜 구매 플로우) · feature-spec.md 2.6/4장. 코드 없음, 스펙만.

## 완료 조건

- [ ] 등급 안내 화면(`/plan`)에 접속하면 무료/프리미엄 비교표(스팟 개수 3개/5개, 공유 카드 워터마크 유무, 체크인+AI여행기 잠금 여부)가 보인다
- [ ] 현재 등급이 무료면 "프리미엄 구매하기" 버튼이 보인다
- [ ] "프리미엄 구매하기" 클릭 → 가짜 결제 화면(가격, 결제수단 선택 UI) → "결제하기" 클릭 → 완료 화면 → 등급이 프리미엄으로 전환된다 (실제 PG사 연동 없음)
- [ ] 등급이 프리미엄으로 전환된 뒤에는 `/plan`에서 "프리미엄 이용 중" 상태가 보이고, 데모 편의를 위해 "무료로 되돌리기" 버튼으로 다시 무료 등급으로 전환할 수 있다
- [ ] 등급이 프리미엄이면 코스 생성 결과 화면에 스팟이 5개 나온다 (무료는 기존과 동일하게 3개)
- [ ] 등급이 프리미엄이면 공유 카드 이미지에 워터마크 문구("동네 큐레이터로 만듦")가 빠진다. 무료는 기존과 동일하게 워터마크 포함
- [ ] 결과 화면 헤더의 등급 라벨이 실제 등급에 맞게 "무료 등급" / "프리미엄 등급"으로 표시된다 (현재는 "무료 등급"으로 고정돼 있음)
- [ ] 랜딩 화면 헤더에 등급 안내 화면(`/plan`)으로 가는 링크가 보인다

## 확인 방법

1. `npm run dev` 실행
2. `/plan` 접속 → 비교표와 "프리미엄 구매하기" 버튼 확인
3. "프리미엄 구매하기" → 가짜 결제 화면 → "결제하기" → 완료 화면 확인
4. `/plan` 재방문 시 "프리미엄 이용 중" 상태 확인
5. `/`에서 코스 생성 → 결과 화면에 스팟 5개, 헤더 라벨 "프리미엄 등급" 확인
6. "공유하기" → 카드 미리보기에 워터마크 문구가 없는지 확인
7. `/plan`에서 "무료로 되돌리기" → 다시 코스 생성 시 스팟 3개, 워터마크 있음으로 돌아오는지 확인
8. 자동화 테스트: `tier.ts` 순수 함수 테스트(vitest), mock API의 tier별 스팟 개수 응답 테스트(vitest). 구매 플로우 화면 전환·워터마크 렌더링은 수동 확인
