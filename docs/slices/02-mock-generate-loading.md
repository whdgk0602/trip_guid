## 코스 JSON 스키마 (확정)

```json
{
  "title": "강남역 골목 산책",
  "intro": "퇴근길에 만나는...",
  "spots": [
    {
      "id": "spot-1",
      "name": "...",
      "category": "카페",
      "description": "...",
      "address": "서울 강남구 ..."
    }
  ]
}
```

- `spots`는 항상 3개 고정 (등급 게이팅 전)

## 건드릴 파일

- **새로 만들 파일**: `src/app/api/routes/generate/route.ts` — POST 요청을 받아 1.5~2초 인위적 지연 후 위 스키마의 고정 JSON을 반환하는 mock Route Handler. 코스 타입은 이 파일에 인라인으로 정의
- **고칠 파일**:
  - `src/app/generate/page.tsx` — 서버 컴포넌트(1초 지연 후 입력 텍스트만 표시)를 클라이언트 컴포넌트로 교체. mount 시 mock API를 호출하고, 고정 타이머로 "주변 장소 찾는 중" → "코스 만드는 중" 문구를 전환하다가 응답을 받으면 mock 데이터를 화면에 표시. 코스 타입은 이 파일에도 인라인으로 정의(중복 허용)
- **삭제할 파일**: `src/app/generate/loading.tsx` — `/generate`가 클라이언트 컴포넌트로 바뀌면서 Next.js 파일 컨벤션 기반 Suspense 로딩이 더 이상 맞지 않아 제거. 로딩 문구는 `generate/page.tsx` 내부 상태로 관리

## 확인 방법

1. `npm run dev` 실행
2. mock API 단독 확인: `curl -X POST http://localhost:3000/api/routes/generate` 호출해 위 스키마에 맞는 JSON(스팟 3개)이 오는지 확인
3. `/`에서 10~300자 텍스트를 입력해 제출 → `/generate`에서 "주변 장소 찾는 중" → "코스 만드는 중" 순서로 문구가 바뀌는지 육안 확인
4. 응답 수신 후 mock 데이터(제목/스팟 3개)가 화면에 표시되는지 확인
5. 자동화 테스트는 이번에도 없음 (수동 확인만 — API 응답 자체가 고정값이라 별도 순수 함수 로직이 없음)
