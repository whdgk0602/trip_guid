# 기능 10 (Phase 1): 목업을 실제 API로 교체하고, 무료 LLM 위에서도 안정적으로 동작한다

> PRD FR-2·3·4·8·12, NFR-3·5·6 · 2026-11-12~13 구현. 01~09는 Phase 0(목업) 스펙이며, 이 문서는 그중 바뀐 부분만 정리한다. 실행 기록은 `PLAN.md`.

## 완료 조건

- [x] **FR-2 지명 추출 + 지오코딩** — LLM이 경로 문장에서 지명을 뽑고 카카오 키워드/주소 검색으로 좌표화. 동명이소는 직전 지점과 가장 가까운 후보, 30km 넘게 튀면 제외. 행정구역명(…동/…구)은 주소 검색 우선
- [x] **FR-3 장소 큐레이션** — 경로 지점(최대 3) 주변 카페·식당·공원·볼거리·문화를 카카오에서 찾아 카테고리 중복 없이 무료 3/프리미엄 5. 반경 500m → 1km → 2km 확대, 부족하면 찾은 만큼 + 안내
- [x] **FR-4 코스 텍스트** — LLM이 제목·소개·스팟 설명(해요체). 이름·카테고리·주소 밖의 사실 금지, 응답 검증, 실패 시 템플릿
- [x] **FR-8 서버 갤러리** — 공개 코스만 Upstash Redis에 저장, 생성 API의 HMAC 서명으로 위조 차단, 소유자는 `sha256(anonymousId)`만
- [x] **FR-11/12 체크인 사진 · AI 여행기** — 사진은 긴 변 640px JPEG로 줄여 localStorage에 저장(용량 부족 시 그 사진만 빼고 저장 + 안내). 여행기는 기록 기반 1인칭 일기체, 실패 시 템플릿을 보여주되 저장하지 않고 재시도 버튼
- [x] **NFR-3 에러·재시도** — 입력 문제(장소 인식 실패·위치 못 찾음·주변 장소 없음)는 예시와 함께 재입력, 외부 API 장애는 재시도
- [x] **NFR-5 비용·한도** — LLM 결과 캐시(`unstable_cache`, 30일), 모델 폴백 직접 순회, 단계별 시간 예산(추출 8s·문구 10s·여행기 12s), LLM 불가 시 규칙 기반 추출/템플릿
- [x] **NFR-6 데이터 유실 안내** — 저장 모달·내 코스·등급 화면

## 안 되는 경우 / 알려진 한계

- OpenRouter 무료 한도는 **계정 단위**라 로컬 테스트가 운영 한도를 같이 씀 → 로컬에서는 `OPENROUTER_API_KEY`를 비워 규칙 기반으로 개발 가능
- 등급(프리미엄)은 브라우저에만 있어 서버 API(여행기 등)에서 검증하지 않음
- 체크인 사진은 그 브라우저에만 있음 (기기 간 이동·백업 없음)

## 확인 방법

1. `npm test` — 서버 로직(`src/lib/server`)과 클라이언트 로직(`src/lib`)을 외부 서비스 없이 검증
2. 운영 https://trip-guid.vercel.app — 경로 입력 → AI 코스 → 공개 저장 → 갤러리 노출 → 비공개 전환 → 사라짐
3. 프리미엄 전환 후 `/my/[id]`에서 사진 포함 체크인 → 새로고침해도 사진 유지 → 여행기 생성
