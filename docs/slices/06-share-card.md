# 기능 6: 사용자가 결과 화면에서 코스를 공유용 이미지 카드로 저장할 수 있다

> PRD FR-6 · feature-spec.md 2.3/2.5. 코드 없음, 스펙만.

## 완료 조건

- [ ] 결과 화면에서 "공유하기"를 누르면 카드 미리보기(코스 제목 + 스팟 이름 목록 + 워터마크 문구)가 보인다
- [ ] "이미지 저장"을 누르면 미리보기 카드가 PNG 파일로 다운로드된다
- [ ] "닫기"를 누르면 미리보기가 닫히고 결과 화면으로 돌아간다

## 안 되는 경우

- 해당 없음 (mock 데이터 기반이라 실패할 입력이 없음). 다만 카드를 이미지로 변환하는 라이브러리가 외부 폰트(Google Fonts) 로딩 이슈로 렌더링에 실패할 수 있으니, 확인 방법 7번에서 실제로 다운로드된 PNG를 열어 폰트/텍스트가 깨지지 않는지 반드시 눈으로 확인할 것

## 이번에 안 하는 것

- **링크 복사 기능** — 지금 코스는 고유 URL(`/routes/:id` 같은)이 없고 `/generate?text=...`는 매번 같은 mock 데이터를 재생성하는 임시 화면이라 "복사할 실제 링크"가 없음. 저장된 코스가 자기 URL을 갖는 구조가 생기면 그때 추가
- **프리미엄 워터마크 제거** — 등급(무료/프리미엄) 시스템이 아직 없음(별도 태스크). 이번엔 항상 워터마크 포함
- MVP_DESIGN 비주얼 디자인 — 다음 디자인 적용 라운드. 이번엔 최소 스타일(01~05와 같은 수준)
- "다시 만들기" 버튼 — 별도 범위

## 건드릴 파일

- **새 의존성 설치**: `html-to-image` (DOM 노드를 PNG로 변환하는 라이브러리). `npm install html-to-image`로 설치하고 `package.json`/`package-lock.json`에 반영
- **새로 만들 파일**:
  - `src/app/generate/ShareModal.tsx` — 카드 미리보기(제목 + 스팟 이름 최대 3개 + "동네 큐레이터로 만듦" 워터마크 문구) + "이미지 저장" + "닫기" 버튼. `html-to-image`의 `toPng`로 카드 DOM을 PNG로 변환해 다운로드
  - `src/lib/shareFileName.ts` — `buildShareFileName(title: string): string`. 코스 제목을 파일명으로 안전하게 바꾸는 순수 함수(공백은 `-`로, 파일명에 못 쓰는 특수문자는 제거, 예: "강남역 골목 산책" → `강남역-골목-산책.png`)
  - `src/lib/shareFileName.test.ts`
- **고칠 파일**: `src/app/generate/GenerateClient.tsx` — 헤더에 "공유하기" 버튼 추가, 클릭 시 `ShareModal` 열기

## 확인 방법

1. `npm install html-to-image` 실행 후 `npm run dev`
2. `/`에서 코스 생성 → 결과 화면에서 "공유하기" 클릭 → 카드 미리보기가 뜨는지 확인
3. "이미지 저장" 클릭 → PNG 파일이 다운로드되는지 확인
4. 다운로드된 PNG 파일을 실제로 열어서 제목/스팟 이름/워터마크 텍스트가 깨지지 않고 보이는지 확인 (폰트 렌더링 이슈 없는지)
5. "닫기" 클릭 → 결과 화면으로 돌아가는지 확인
6. 자동화 테스트: `buildShareFileName` 순수 함수 테스트(vitest) — 공백 치환, 특수문자 제거 등. 카드 렌더링·PNG 변환 자체는 브라우저 API(canvas) 의존이라 수동 확인
7. `npx eslint .` / `npx next build`로 새 의존성이 빌드를 깨지 않는지 확인
